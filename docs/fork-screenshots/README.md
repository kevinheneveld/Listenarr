## ⚠️ Scrub before committing
These come from a live instance. Before saving any image, remove:
- the hostname / reverse-proxy domain in the browser URL bar
- private IPs and local filesystem paths
- API keys / indexer credentials (settings panels)
- any real titles/authors you'd rather not publish

Crop the browser chrome or screenshot the app viewport only.
